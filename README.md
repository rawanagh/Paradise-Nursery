# Paradise Nursery

Paradise Nursery is a houseplant shopping application built with React, Redux Toolkit, and React Router.

## Features
- Landing page with company introduction and a Get Started button
- About Us page
- Plant catalog grouped into three categories
- Add-to-cart controls and a dynamic cart item count
- Shopping cart with quantity updates, item removal, totals, and checkout placeholder

## Run locally
1. Install Node.js.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown in the terminal.

## Technologies
React, Vite, Redux Toolkit, React Redux, and React Router.
